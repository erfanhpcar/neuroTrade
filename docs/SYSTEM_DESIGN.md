## ۱. ساختار کلان پروژه (High-Level Architecture)

این سیستم از ساختار **دکاپل (Decoupled)** استفاده می‌کند. هسته پردازشی و مأمورها (Agents) به دلیل پشتیبانی بهتر از کتابخانه‌های هوش مصنوعی و معاملاتی در پایتون نوشته می‌شوند، و داشبورد مدیریتی و فرانت‌اند با فریم‌ورک مدرن **Next.js** پیاده‌سازی خواهد شد. ارتباط این دو بخش به صورت دوطرفه و بلادرنگ (Real-time) خواهد بود.

Plaintext

```
+-------------------------------------------------------------+
|                Frontend Dashboard (Next.js)                 |
|   - تنظیمات ریسک و سرمایه      - مانیتورینگ زنده ایجنت‌ها     |
|   - فعال/غیرفعال‌سازی سیستم    - نمودار سود/زیان و پوزیشن‌ها   |
+-------------------------------------------------------------+
                              ^
                              | (WebSockets / REST API)
                              v
+-------------------------------------------------------------+
|                Backend AI Engine (FastAPI)                  |
|   - مدیریت ایجنت‌ها (LangGraph)                             |
|   - مدیریت پایگاه داده و کش (PostgreSQL + Redis)             |
+-------------------------------------------------------------+
                              |
        +---------------------+---------------------+
        |                                           |
        v                                           v
+-----------------------+                   +-----------------------+
|   Data & News APIs    |                   |  Execution layer      |
| - CoinGecko / Binace  |                   | - CCXT Library        |
| - CryptoPanic (News)  |                   | - Testnet / Live API  |
+-----------------------+                   +-----------------------+

```

## ۳. معماری سیستم چند عاملی (Multi-Agent Subsystem)

سیستم به جای یک هوش مصنوعی همه‌کاره، شامل ۴ مأمور تخصصی است که در یک ساختار گرافی با یکدیگر تعامل دارند:

Plaintext

```
[شروع چرخه زنده] 
       |
       v
+-----------------------------------------+
| 1. ایجنت جمع‌آوری و فیلتر داده (Scraper)  | ---> واکشی قیمت، حجم، اردر بوک و اخبار داغ
+-----------------------------------------+
       |
       v
+-----------------------------------------+
| 2. ایجنت تحلیل استراتژی (Strategist)    | ---> بررسی الگوهای بازار و مناطق عرضه/تقاضا
+-----------------------------------------+
       |
       v
+-----------------------------------------+
| 3. ایجنت تحلیل سنتیمنت (Sentiment)      | ---> ارزیابی اخبار و تاثیر فاندامنتال آن‌ها روی مارکت
+-----------------------------------------+
       |
       v
+-----------------------------------------+
| 4. ایجنت مدیریت ریسک و اجرا (Risk/Exec) | ---> محاسبه پوزیشن سایز، بررسی سقف ضرر و ارسال دستور
+-----------------------------------------+

```

### شرح وظایف دقیق هر ایجنت:

1. **Data Retriever Agent:** وظیفه دارد هر X دقیقه یک‌بار، دیتای زنده را از صرافی و فیدهای خبری بگیرد و داده‌های بی‌ارزش را فیلتر کند.
2. **Technical Strategist Agent:** تحلیل تکنیکال پیشرفته (نه فقط اندیکاتورهای ساده، بلکه بررسی ساختار مارکت، نواحی عرضه و تقاضا، نقدینگی و روند اصلی).
3. **Fundamental & News Agent:** متن اخبار را از API دریافت کرده و با مدل‌های زبانی کوچک‌تر (مثل GPT-4o-mini) تحلیل می‌کند که آیا این خبر روی قیمت اثر آنی، میان‌مدت یا خنثی دارد.
4. **Risk & Execution Agent (اتومیشن قطعی):** ورودی‌های تحلیل را دریافت می‌کند. اگر تاییدیه صادر شد، طبق فرمول‌های ریاضیِ از پیش‌تعیین‌شده (مثلاً ریسک ثابت ۱٪ از کل سرمایه در هر معامله) حجم دقیق پوزیشن، نقطه ورود، حد سود (TP) و حد ضرر (SL) را مشخص کرده و به صرافی ارسال می‌کند.

## ۴. نیازمندی‌های کلیدی APIها و اتصالات (Integrations)

- **داده‌های معاملاتی و اجرای پوزیشن:** استفاده از کتابخانه **CCXT**. این کتابخانه به بیش از ۱۰۰ صرافی متصل می‌شود. برای شروع از **Binance Testnet** یا **Bybit Testnet** استفاده می‌کنیم تا بدون ریسک مالی، سیستم را تست کنیم.
- **دیتا فید اخبار:** APIهای اختصاصی مانند **CryptoPanic API** یا **Messari**.
- **مدل‌های هوش مصنوعی (LLMs):**
  - برای بخش بحث و تصمیم‌گیری نهایی (Reasoning): **Claude 3.5 Sonnet** یا **GPT-4o**.
  - برای کارهای ارزان‌تر مثل خلاصه‌سازی اخبار: **GPT-4o-mini** یا مدل‌های متن‌باز مثل **Llama 3**.

## ۵. امنیت و لایه محافظ حیاتی (The Risk Firewall)

برای جلوگیری از هرگونه رفتار غیرقابل‌پیش‌بینی توسط هوش مصنوعی، قوانین زیر در سطح لایه کد (و نه پرامپت) قفل می‌شوند:

1. **API Keys Control:** در صرافی، دسترسی API Key فقط برای `Enable Reading` و `Enable Spot/Margin Trading` فعال می‌شود و گزینه‌ی `Withdrawal` (برداشت وجه) **باید کاملاً غیرفعال باشد**.
2. **Hardcoded Risk Limits:** سقف مجاز ضرر روزانه (مثلاً حداکثر ۳٪ کل حساب در روز) در کد قرار داده می‌شود. در صورت لمس این عدد، سیستم تا ۲۴ ساعت آینده به طور خودکار خاموش شده و هیچ دستوری صادر نمی‌کند.
3. **Human-in-the-loop (اختیاری):** یک سوییچ در فرانت‌اند تعبیه می‌شود با عنوان `Semi-Auto / Full-Auto`. در حالت Semi-Auto، ایجنت موقعیت را پیدا می‌کند، مدیریت سرمایه را انجام می‌دهد و روی فرانت‌اند دکمه‌ی "تایید نهایی" را به شما نشان می‌دهد تا تاییدش کنید. بعد از اطمینان کامل، می‌توان آن را روی Full-Auto گذاشت.
